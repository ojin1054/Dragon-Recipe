# 세 종족 (사람 · 오크 · 엘프)

비행 맵에 세 종족의 마을이 있고, 드래곤이 누구를 공격하느냐에 따라 호감도가 바뀐다.
호감도 단계에 따라 병사가 드래곤을 쏘거나, 제물과 축복을 보낸다. 가끔 두 종족이 전쟁을 벌이고, 사이가 좋은 쪽이 참전을 요청한다.

코드: `Assets/_Project/Scripts/Tribes/`. 수치는 `GameConfig > 종족 (TribeSettings)`.

## 호감도 (-100 ~ 100)

| 행동 | 사람 | 오크 | 엘프 |
|---|---|---|---|
| 사람 공격 | −15 | +10 | +3 |
| 오크 공격 | +10 | −15 | +3 |
| 엘프 공격 | | | −40 |
| 엘프 땅(마을 70m 안)에서 먹이 사냥 | | | −2 |

- 공격받은 쪽이 잃는 양이 상대가 얻는 양보다 커서, 사람과 오크를 번갈아 때려 둘 다 올릴 수는 없다.
- 비행 한 번마다 처음 값(사람 0, 오크 −25, 엘프 10) 쪽으로 2씩 돌아간다. 엘프의 원한(처음 값보다 낮을 때)은 0.4씩만 풀린다.

## 단계와 효과

| 단계 | 호감도 | 병사 | 제물 | 축복 |
|---|---|---|---|---|
| 적대 | ≤ −60 | 사거리 안이면 쏨, 병사 +3 | | |
| 경계 | ≤ −20 | 마을 땅(45m)에 들어오면 쏨, 병사 +1 | | |
| 중립 | | 안 쏨 | | |
| 우호 | ≥ 20 | 안 쏨, 지나가면 펄쩍 반김 | 50% (엘프 25%) | 오크: 드는 힘 ×1.15 · 엘프: 활공 ×1.08 |
| 숭배 | ≥ 60 | 더 크게 반김 | 매번 + 50% 하나 더, 25% 희귀 | 사람: 받는 피해 ×0.85 · 오크: 드는 힘 ×1.3, 체력 ×1.15 · 엘프: 활공 ×1.12, 스태미나 회복 ×1.25 |

- 병사 전투 방식
  - 사람: 활.
  - 오크: 느리지만 아픈 창(14).
  - 엘프: 85m 밖에서 정확하게 쏘는 저격.
- 쏘기 전에 시위를 당기는 동안 무기 끝이 빨개진다.
- 제물 (`sheep` / `boar` / `golden_melon`)
  - 제단에 놓였다가 창고에 자리가 생기면 창고로 들어간다.
  - 제단에는 최대 6개까지 쌓인다.
- 마을 깃발 색이 단계를 나타내고, 호감도가 바뀌면 번쩍인다.
  - 빨강 = 적대, 주황 = 경계, 회색 = 중립, 초록 = 우호, 금색 = 숭배.

## 전쟁

1. 전쟁이 없고 쿨다운(4번)이 끝났으면, 비행 한 번마다 20% 확률로 전쟁이 일어난다.
   - 어느 두 종족이 싸울지의 비율은 사람-오크 3 : 사람-엘프 1 : 오크-엘프 1.
2. 우호 이상인 편이 참전을 요청한다. 둥지 화면의 전쟁 카드에서 "참전" 또는 "거절"을 고른다.
   - 거절하면 요청한 편이 −5.
   - 참전하는 순간 적 편이 −10이 되고, 그 적 편 병사는 단계와 상관없이 드래곤을 쏜다.
   - "참전"을 누르면 곧바로 비행 씬으로 넘어가 첫 방어전이 시작된다. 그다음 방어전은 둥지에서 평소처럼 비행을 시작하면 된다.
3. 전쟁 중에는 두 마을 한가운데에 전쟁터가 생기고, 양쪽 병사가 서로 쏜다.
4. 참전 중 비행은 **방어전**이다.
   - 둥지 동굴 대신 편든 쪽 마을 앞 망루에서 달려 나가 이륙한다. 망루는 적이 오는 쪽을 바라보는 긴 나무 발판이다.
   - 이륙하고 6초 뒤부터 25초마다 적 무리가 적 마을 쪽에서 편든 쪽 마을로 몰려온다. 3무리이고, 3 → 5 → 7명으로 늘어난다.
   - 침입자는 횃불을 들고 있고, 행군하면서 드래곤을 쏜다.
   - 침입자가 마을 가운데 14m 안에 닿으면 마을이 뚫린다.
     - 방어 칸(비행마다 5칸)이 하나 줄어든다.
     - 승률이 −8% 깎이고, 편든 쪽 호감이 −2 떨어진다.
     - 주민이 쓰러지고 깃발이 번쩍인다.
   - 드래곤이 침입자를 쓰러뜨리면(`Hit` / `AttackArea`) 한 명마다 승률이 +4% 오른다.
     - 호감도 변화는 ×0.25로 작다. 수십 명을 쓰러뜨려도 호감이 한꺼번에 치솟지 않게 하려는 것이다.
   - 편든 쪽 병사도 침입자를 쏘지만 느리고, 승률에는 들어가지 않는다.
   - 비행 HUD 오른쪽 위에 방어 상태가 보인다.
     - 편든 쪽 얼굴 옆: 방어 칸 ●○
     - 적 얼굴 옆: 남은 침입자 수 x N, 아직 오지 않은 무리 ▲
5. 3번 비행하면 승패가 난다.
   - 승률 = 50% + 쓰러뜨린 적 × 4% − 뚫린 횟수 × 8% (5% ~ 95%). 편든 쪽을 공격하면 깎인다.
   - 이기면: 편든 쪽 +25, 그 종족 제물 3개(50% 희귀), 승전 축복(속도 ×1.1, 스태미나 ×1.15)이 3번 비행 동안 유지된다.
   - 지면: 편든 쪽 −10.
   - 진 종족은 3번 비행 동안 병력이 절반이 된다.

## 공격 · 스킬에서 부르는 API

드래곤 공격 기능은 따로 만드는 중이다. 맞았을 때 아래를 부르면 호감도와 전쟁 승률에 반영된다.

```csharp
var world = TribeWorld.Instance;                       // 비행 씬에 하나 (스스로 붙음)
world.MembersIn(center, radius);                       // 범위 안 주민·병사 (쓰러진 자 제외)
world.Hit(member);                                     // 한 명 쓰러뜨림 + 호감도 반영
world.AttackArea(center, radius);                      // 범위 공격: 종족마다 한 번만 반영
world.Stun(member, seconds);                           // 기절·둔화 (호감도 변화 없음)
world.Knockback(member, push);
world.ClearProjectilesIn(center, radius);              // 날아오는 화살·창 지우기
world.TerritoryAt(point, out Tribe tribe);             // 그 자리가 어느 종족 땅인지

DragonCare.ReportTribeAttack(Tribe.Orc);               // 종족을 직접 지정해 반영할 때
```

`TribeMember`: `Tribe`, `IsSoldier`, `IsWarParty`, `IsDown`, `IsStunned`.

## 아직 임시인 것

- 마을·주민은 프리미티브로 만들었고, 종족 얼굴 아이콘은 코드로 그린 16×16 도트다.
- 콜라이더가 없어 드래곤이 마을에 부딪혀도 추락하지 않는다.
